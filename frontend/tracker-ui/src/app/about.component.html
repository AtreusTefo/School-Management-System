About

Built to replace remembering with a record.

Assignment Tracker started from a problem every teacher recognises: the work has been set, some of it has been handed in, and the only place that fully exists is in somebody's head, a spreadsheet, and a pile of paper that disagree with each other.

The answer here is deliberately narrow. One shared list of assignments and their submission state, held to rules the database itself enforces, rather than a broad system that tracks everything loosely.

What it is

Assignment Tracker is a full-stack web application for tracking assignment submission state in a school. A teacher sets one piece of work against a course, and it becomes a submission for every student enrolled in that class. Students hand in a PDF. Teachers mark what arrives, and the marks roll up into per-subject percentages and performance levels that are calculated fresh every time they are read.

Around that sits the administration it needs to be usable: an administrator onboards accounts, maintains the subjects, classes and courses that define who is taught what by whom, and can review an audit log of every change the system has made.

How it is built

A Spring Boot REST API in Java backs an Angular single-page interface, with SQL Server holding the data. The two halves are deployed separately and share nothing but the API contract between them.

The schema is managed by versioned migrations, and the application is never permitted to alter it at runtime - a mismatch between what the code expects and what the database holds stops the application at startup rather than surfacing later as corrupt data. An automated test suite covers the business rules, the error contract, concurrency, and the constraints themselves.

Deliberate limits

This system tracks assignments and the marks attached to them. It has no attendance register, no term or period timetable, and no messaging. Those are real needs, and they are not what this was built for - pretending otherwise would only move the confusion somewhere less visible.
