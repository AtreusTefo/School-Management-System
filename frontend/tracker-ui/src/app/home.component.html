What this system is not

This is an assignment tracker, not a whole school management suite. There is no attendance register, no term or period timetable, and no messaging or notifications. "Timetable" here means which teacher teaches which subject to which class - not when those lessons happen. Saying so plainly is more useful than implying otherwise.
